# Supplemental upstream license documents

These documents fill gaps in installed wheel license files. `sources.json` records exact-version source archive URLs and verified archive SHA-256 values. `upstream-sources.json` records immutable official upstream URLs, commits and file hashes; when no matching release tag was available, the listed upstream commit was used. cobble 0.1.4 declares 2-Clause BSD in its README and ships no standalone license file; its original README is retained without inventing a copyright notice.

The bundle also retains all license documents distributed inside its Python packages, including nested BUILD_LICENSES and LICENCE files. Model weights are not part of these artifacts.
